## Descrição do projeto:
Foi criado um sistema que vai gerenciar uma estética automotiva, no qual consiste em realizar o cadastramento de veículos pela placa
(garantindo a unicidade de cada veículo) agendamento de serviços e qual tipo de serviço irá ser feito. Além disso, será integrado dados do cliente 
como: nome/telefone, para obtermos uma relação do proprietário com seu carro. O sistema impede que um mesmo veículo tenha dois agendamentos ativos
no mesmo período, evitando conflitos de agenda. 

## Pré-requisitos

- Node.js (versão 18 ou superior)
- npm (instalado junto com o Node.js)
- MongoDB (Foi utilizado o Atlas, MongoDB em nuvem)
- Git
